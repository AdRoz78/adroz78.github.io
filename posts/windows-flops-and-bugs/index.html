A small collection of bugs that Windows has had in the close past, mostly Windows 11.
There is no particular order.

Bugs

This isn't meant to be taken (too) seriously!

MacOS has bugs, Linux has bugs, bugs existed, exist and will exist. Though, some of these are quite embarrasing.

1. Accessing localhost was broken, breaking the workflows of some developers.
2. Keyboard and mouse input was broken in recovery mode, ironically making recovery harder.
3. Task manager roleplayed as the Hydra virus and duplicated itself each time it was closed with the X button.
4. This time it's not creating a bug, but patching it... years later. To be specific "Update and Shutdown" usually restarting your PC.

7. ESU updates were blocked, and a normal update had to be pushed to fix it.
8. HDR content was tinted red. Also weird interactions related to running a full screen app in the background.
